# 3-Axis CNC Wood Router

## Project Overview
This repository contains the mechanical design files for a **3-axis CNC (Computer Numerical Control) machine** specifically designed for wood cutting and engraving. This project was developed as part of my **Undergraduate Thesis in Mechanical Engineering** at **ULPGL**.

## Technical Specifications
* **Machine Type:** 3-Axis Router
* **Application:** Woodworking (cutting, milling, and engraving)
* **Software Design:** SolidWorks
* **Control System:** GRBL / CNCjs

## Repository Content
* `/CAD`: SolidWorks assembly and part files (Pack and Go .zip).
* `/Exports`: Universal 3D formats (.STEP / .IGES) for cross-platform viewing.
* `/Documentation`: Technical report and mechanical calculations.
